Add JAAL to Chrome in four steps

While the Web Store listing is in review, load the extension directly. It takes about a minute and works in Chrome, Edge and Brave.

  1. Download the extension

    One zip. Unzip it somewhere you will not delete it, like Documents.

    Download jaal-extension.zip
    jaal-extension
    jaal-extension.zip

  2. Open the extensions page

    Paste this into the address bar. Chrome does not let websites open it for you.

    chrome://extensions

  3. Turn on Developer mode

    The switch is in the top-right corner of the extensions page.

    ExtensionsDeveloper mode

  4. Load unpacked, then pin it

    Click Load unpacked, choose the unzipped jaal-extension folder, then pin JAAL from the puzzle icon.
