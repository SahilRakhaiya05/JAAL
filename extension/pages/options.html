Stopping confirmed sites

Confirmed sites are always sent to a JAAL warning page. Granting site access lets Chrome do this before the page loads at all (a declarativeNetRequest redirect), instead of right after it starts.

    Server

    Privacy, in plain words

    • Every message is scored on this device first. Almost all of them stop there.
    • For weak signals, JAAL compares an 8-character hash prefix against a list it downloaded. Only a prefix match, or a strong pattern match, sends that one message's text to the JAAL graph.
    • Pastes: only the UPI handle, account number or wallet address is checked, never the rest of the clipboard, and only during a paste you make.
    • Sites: the domain is hashed on-device; the domain is only sent when its prefix is on the reported list.
    • Downloads: file names are matched on-device. Nothing is uploaded.
    • You are identified by a salted hash of a random device id, never by name, number or email.
